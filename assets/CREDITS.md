# Asset credits

Every sound and texture file in `assets/` gets one line here: file, source, author, licence.
Sounds come from CC0 libraries only (Freesound, OpenGameArt) as Ogg. Models and textures are
generated in code and need no line unless a file is added.

Files in `assets/sounds/` are cut and converted from the owner's downloads by
`tools/process-sounds.mjs` (see `assets/sounds/manifest.json`). **"link pending"** means the
owner has not sent the page URL yet; such files must not ship in a release until it is filled in.
